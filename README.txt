SkyCast - Offline edition (no API)
Shows typical monthly weather from past climate data in data/climate.csv.
Run: double-click run.bat (Windows) or ./run.sh (Mac/Linux), then open the link it prints.
To use real data: replace data/climate.csv keeping the same columns
(city,country,region,lat,lon,month,avg_high_c,avg_low_c,rain_mm,rain_days,humidity_pct).
NOTE: bundled values are approximate climate averages, not an official dataset.
